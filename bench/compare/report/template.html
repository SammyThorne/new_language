Response rate

How many requests each server answers per second

256 connections send requests back to back for 5 seconds. Each endpoint does a different amount of work: a small JSON object, a path parameter, a list of 20 records, and a POST that parses and totals an order.

Load bearing

What happens as load rises

Left: requests per second on GET /users/42 as the number of open connections grows. Right: latency when requests arrive at a fixed rate, from 1,000 to 400,000 a second. A request that had to wait for the server to finish the one before is timed from when it was due, so falling behind shows as latency. A server stops at the first rate it cannot hold.
